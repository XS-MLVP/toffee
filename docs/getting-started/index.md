# 从第一个测试开始

这份教程用一个 **8 位累加器**，带你从一条断言写到流水输入、参考模型和覆盖率。
先运行例子，再改一个地方看看结果；不需要先读完整 API 手册。

前半部分只需要 Python。仓库提供了一个用 Python 模拟的累加器，方便练习输入和时钟，
不需要先安装 RTL 仿真器。接入真实硬件的方法放在最后一节选读中。

## 代码在哪里

主要看两个文件：

```text
examples/getting_started/
├── test_accumulator.py   按教学顺序排列的测试、驱动、监视器和模型
└── toy_dut.py            已写好的累加器
```

每一页会指出当前要看的测试函数，并给出只运行它的命令。
如果使用仓库中的文件，不要重复粘贴页面里的代码。
如果想从空文件跟着写，就按章节顺序追加，保留前面用到的定义和 import。

`# region` 和 `# endregion` 是帮助编辑器折叠代码的注释，不影响运行。

## 先认识四个词

- **DUT**：被测设计。这里是累加器，实际项目里也可能是缓存、总线接口或运算单元。
- **激励**：送给 DUT 的输入，例如“加上 3”。
- **期望值、实际值**：按规格算出的结果、从 DUT 读到的结果。测试比较这两个值。
- **事务**：一次完整操作，例如“加上 3 并取得结果”。它可能跨越多个时钟周期。
